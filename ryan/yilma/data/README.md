# Yilma Data Directory

This directory groups non-page assets and runtime files:

- `models/` face-detection model files
- `training_images/` enrolled face images used for training
- `trainer/` generated trainer artifacts (`trainer.yml`, `labels.npy`)
- `scan_images/` scan snapshots used by logs/UI
- `db_snapshots/` SQL backup/reference files

Legacy paths in `ryan/yilma/` are kept as compatibility symlinks.
