# Biometric Access System (Project Map)

Start here if you are new:
- Crash course: `CRASH_COURSE_ONE_PAGER.md`

Top-level app folders:
- `ryan/`: Classroom scan UI + PHP backend APIs + shared DB layer.
- `ryan/yilma/`: Admin/professor portals + Python face recognition + face enrollment tooling.

Primary entry points:
- Classroom scan screen: `ryan/index.php`
- Classroom scan API: `ryan/labels.php`
- Admin/professor login: `ryan/yilma/index.php`
- Admin console: `ryan/yilma/admin.php`
- Recognition Flask app: `ryan/yilma/flaskRecognize.py`
- Recognition engine: `ryan/yilma/recognize.py`
- Shared DB class: `ryan/database.php`
